# Changelog

## 0.1.3

- Open an existing image in a sketch: from the Explorer context menu, the Command Palette, or with `Ctrl+Alt+S` / the status bar camera while an image is open in VS Code's image preview. The sketch works on a copy; the original file is never changed.
- Supported: PNG, JPG, WebP, GIF, BMP and SVG (rendered to a bitmap, at least 2048 px on the longer side).

## 0.1.2

- README: screenshots of the Sketch tab and the command.

## 0.1.1

- The status bar camera icon now shows right after VS Code starts, not only after the first screenshot.

## 0.1.0

Initial release.

- Screenshot of the visible part of an Integrated Browser tab, without reloading the page (WebGL canvases included).
- Sketch editor: pen, arrow, rectangle, text, eraser, colors, stroke widths, undo and redo.
- Select an area and copy it to the clipboard together with the drawing.
